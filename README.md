# 7.3. Подъём инфраструктуры в Yandex Cloud — Соснин Александр

## Задание 1. Развернуть VPC, 2 веб-сервера, бастион-сервер

### Архитектура
- **VPC:** `network-1` с двумя подсетями (`subnet-a`, `subnet-b`).
- **Бастион (`bastion`):** с публичным IP для безопасного доступа из интернета.
- **Веб-серверы (`web-1`, `web-2`):** с приватными IP, доступны только через бастион (ProxyJump).

### Соответствие инструкции по экономии
- Прерываемые ВМ (`preemptible = true`) — скидка до 70%.
- Доля vCPU 20% (`core_fraction = 20`) — скидка до 65%.
- Диски HDD 10 ГБ (вместо SSD).
- RAM 2 ГБ.
